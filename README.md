# 备用机全能通信转发探针 (Magisk / KernelSU 模块)

专为小米澎湃 OS (HyperOS)、OPPO ColorOS 系统打造。
彻底抛弃传统的应用层广播监听 (如 `SMS_RECEIVED`)，利用 Root 权限直接在系统底层轮询 SQLite 数据库。无论系统怎么冻结后台、怎么限制耗电，只要手机开机且有网，你的备用机就不会漏掉任何一条重要信息。

## ✨ 核心特性
- **全能通信监控**：支持短信转发（带双卡标识）、未接来电提醒、已接/拨出记录推送。
- **模块化按需开启**：所有监控功能均可在配置文件中独立开关，丰俭由人。
- **真·系统级保活**：依托 Magisk 开机自启纯 Shell 脚本守护进程，无视任何系统级“电量优化”与“进程查杀”。
- **断网无限重试**：遇到备用机处于电梯、地下室等无信号环境导致推送失败时，脚本会在下一周期自动重发，绝不漏信。
- **防爆存储设计**：自带日志自动轮转清理机制（最高限制 1MB），就算 7x24 小时常年运行，也绝不会撑爆手机 `/data` 分区。

## 💡 安装与配置说明 (⚠️ 必看)

**本模块自带防呆拦截，未配置 Webhook 链接直接刷入会报错失败！**
请严格按照以下步骤进行配置和安装：

1. **下载与解压**：下载本模块的 ZIP 压缩包，并在手机或电脑上解压。
2. **修改配置**：进入 `core` 文件夹，使用文本编辑器（推荐 MT 管理器）打开 `config.conf` 文件。
3. **填入 Webhook**：将 `WEBHOOK_URL=` 后面的占位符修改为你自己真实的钉钉或企业微信群机器人 Webhook 链接。
4. **功能开关 (可选)**：根据需要，将 `ENABLE_SMS` 或 `ENABLE_MISSED_CALL` 等功能开关设置为 `true`（开启）或 `false`（关闭）。
5. **重新打包**：全选解压出来的所有文件和文件夹（确保 `META-INF`、`core` 等在压缩包根目录），**重新打包成 ZIP 格式**。
6. **刷入生效**：打开 Magisk / KernelSU / APatch，刷入你打包好的 ZIP，重启手机即可大功告成。

## ⚙️ 钉钉机器人设置提醒
如果你使用的是钉钉群机器人，在配置机器人的**【安全设置】**时，请选择**【自定义关键词】**，并确保你填写的关键词与 `config.conf` 中的保持一致（默认包含 `【短信】`、`【未接来电】` 等字眼）。否则由于钉钉的安全策略，消息即使发送成功也不会在群里弹出。
