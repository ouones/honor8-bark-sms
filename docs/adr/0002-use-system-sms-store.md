# ADR-0002：补发依赖系统短信库，不新增短信持久存储

## 状态

已接受。依据为用户在 2026-10-20 第二轮需求澄清中对第 1、4 项的明确答复。

## 背景

断网补发可以使用系统短信库作为内容来源，也可以另存待发短信副本。用户明确选择不增加短信持久存储及额外代码工作量，并接受源短信删除后不再补发。

## 决策

- 以系统短信库为补发内容来源，不另存短信正文副本，不新增独立的持久化待发队列。
- 仅保存重启接续所需的发送进度；首次启用建立初始进度，跳过已有历史短信。
- 在系统短信库中仍存在的未发送短信需要补发；源短信被删除后不再要求补发，包括此前已读取但未发送成功的短信。

## 影响与取舍

该方案减少存储、清理和队列恢复逻辑。可靠性依赖源短信仍然存在，不能保证已删除的待发短信继续转发。发送进度的持久化仍然必要，不属于新增短信内容存储。
